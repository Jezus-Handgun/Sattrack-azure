# Log decyzji

| Data | Decyzja | Uzasadnienie |
|---|---|---|
| 2026-11-07 | Zależności i środowisko zarządzane przez **uv** (`pyproject.toml` + `uv.lock`) | Jedno narzędzie zamiast pip i venv. Plik `uv.lock` gwarantuje identyczne wersje bibliotek lokalnie i w obrazie Dockera. |
| 2026-11-07 | **Snapshot danych TLE w repozytorium** (`data/snapshot/`) jako ostatnie źródło danych | Container Apps skaluje do zera, więc po zimnym starcie pamięć jest pusta. Snapshot pozwala aplikacji zawsze coś pokazać, także bez internetu i przy blokadzie CelesTrak. Testy korzystają tylko ze snapshotu. |
| 2026-11-07 | Pobieranie z CelesTrak **najwyżej raz na 2 h na grupę**, leniwie, bez ponowień | CelesTrak aktualizuje dane co ok. 2 h i zwraca HTTP 403 przy częstszych zapytaniach z tego samego IP. Nieudana próba też czeka pełny TTL. Pobrany plik trafia do katalogu cache, więc restart kontenera nie wymusza ponownego pobrania. |
| 2026-11-07 | **Brak bazy danych** | Dane TLE to kilka małych plików tekstowych odświeżanych co 2 h, a wyniki obliczeń są liczone na żądanie. Baza nie wnosi tu nic poza kosztem i dodatkowym zasobem do zabezpieczenia. |
| 2026-11-07 | Obliczenia orbit **na żądanie, bez cache wyników** | Dzięki wektoryzacji (jedna tablica czasów na satelitę) wykres 24 h dla 144 satelitów GNSS liczy się w ok. 0,05 s, więc cache tylko dodałby złożoności. |
| 2026-11-07 | **Frontend bez frameworka i bez kroku budowania** (HTML + CSS + JS, Leaflet i Chart.js z CDN z sumami SRI) | Serwowany przez FastAPI jako pliki statyczne, więc obraz Dockera nie potrzebuje Node.js. Wersje bibliotek są przypięte, a sumy SRI chronią przed podmianą pliku na CDN. Skyplot rysowany ręcznie w SVG. |
| 2026-11-07 | **Logowanie przez wbudowane uwierzytelnianie Container Apps (Easy Auth) z Microsoft Entra ID**, a nie w kodzie aplikacji | Bezpieczeństwo zapewnia platforma: niezalogowane żądanie nie dociera do kontenera, a w kodzie i repozytorium nie ma sekretów ani obsługi tokenów, więc mniej rzeczy może pójść źle. Aplikacja tylko odczytuje nazwę użytkownika z nagłówków `X-MS-CLIENT-PRINCIPAL-NAME` i `X-MS-CLIENT-PRINCIPAL` i używa jej wyłącznie do wyświetlania. |
| 2026-11-07 | **Logi na stdout** (czas, poziom, moduł, komunikat) zbierane przez Log Analytics | Container Apps automatycznie przesyła stdout kontenera do Log Analytics (tabela `ContainerAppConsoleLogs_CL`), więc nie trzeba żadnego dodatkowego SDK. Logowane są: start aplikacji, źródło danych TLE, pobrania z CelesTrak i czas obliczeń wykresu 24 h. |
| 2026-11-07 | **Bez Application Insights** (opcja pominięta) | Pakiet `azure-monitor-opentelemetry` wyraźnie powiększa obraz, a do diagnostyki i zrzutów ekranu wystarczają logi w Log Analytics. |
| 2026-11-07 | **Ciemny motyw interfejsu** (zmiana z jasnego na prośbę autora) | Estetyczniejszy wygląd. Mapa korzysta ze zwykłych kafelków OpenStreetMap przyciemnionych filtrem CSS, bo usługi ciemnych kafelków (np. CARTO) wymagają klucza API. Kolory konstelacji są rozjaśnione, żeby było je dobrze widać na ciemnym tle, także z rzutnika. |
| 2026-11-07 | **Obraz Dockera dwuetapowy**, uruchamiany jako użytkownik bez uprawnień roota | Etap budowania instaluje biblioteki przez uv z `uv.lock`, a obraz końcowy zawiera tylko Pythona, gotowe środowisko, kod i snapshot TLE, bez uv, testów i dokumentacji. Brak roota ogranicza skutki ewentualnego włamania. `.dockerignore` działa jako lista dozwolonych plików, więc do obrazu nie trafi przypadkiem `.env` ani inne prywatne pliki. |
| 2026-11-07 | **Azure Container Apps** zamiast maszyny wirtualnej lub App Service | Usługa bezserwerowa: nie trzeba administrować systemem operacyjnym (aktualizacje, SSH, zapora), jak przy VM. Skalowanie do zera i darmowy limit planu Consumption sprawiają, że koszt projektu jest bliski zera, a App Service kosztowałby stałą opłatę za plan. Wbudowany HTTPS, logowanie (Easy Auth) i integracja z Log Analytics. Aplikacja jest kontenerem, więc da się ją przenieść na dowolną platformę kontenerową. |
| 2026-11-07 | Pobieranie obrazu z ACR przez **tożsamość zarządzaną** (rola `AcrPull`), konto administratora rejestru wyłączone | Brak haseł do rejestru w konfiguracji aplikacji. Uprawnienie ogranicza się do pobierania obrazów z jednego rejestru. |
| 2026-11-07 | Obraz budowany **lokalnie w Dockerze** i wysyłany przez `docker push`, a nie przez `az acr build` | ACR Tasks są wstrzymane dla subskrypcji z darmowymi kredytami, w tym Azure for Students. Lokalny build działa zawsze i ten sam obraz został wcześniej przetestowany lokalnie. |
| 2026-11-07 | Własna sonda zdrowia HTTP na `/healthz` | Domyślna sonda TCP sprawdza tylko, czy port jest otwarty. `/healthz` potwierdza, że aplikacja odpowiada, a przy tym niczego nie liczy, więc sonda jest tania. |
